# FundReady AI

An AI-powered solution built at the Cascadia AI Hackathon, combining LangGraph, Claude, Apify, Box, and AWS (EC2/Amplify) to help streamline fundraising readiness workflows.

## Overview

FundReady AI was built solo during a hackathon to explore how agentic AI workflows can assist with fundraising-related research, document handling, and readiness assessment.

## Tech Stack

- **LangGraph** — agent orchestration
- **Claude** — reasoning and generation
- **Apify** — web scraping / data collection
- **Box** — document storage and management
- **AWS EC2 / Amplify** — deployment and hosting

## Status

This project was built and demoed as a hackathon submission. Contributions, issues, and forks are welcome.
